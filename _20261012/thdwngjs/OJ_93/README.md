# 문제 해석
Left / Right 편대에서 각 드론은 D 이상의 거리를 가짐
L과 R 드론 쌍 중에 거리가 D 미만인 쌍이 있다면 그 중 가장 가까운 거리를 출력함

# 아이디어
1. 완탐
  (N/a) * (N-N/a) -> O(N^2) N은 100,000이기에 완탐은 안됨
2. C보다 D 이상 멀어지면 D 미만인 쌍이 만들어질 수 없음
3. 정렬?
  정렬을 통해서 x축 또는 y축을 기준으로 정렬 한 이후에 비교하면 비교 양이 줄어드나? 
  3_1. C 축과의 거리 기준 오름차순
    -> 잘 와닿지 않음 일단 시도?
  3_2. y 내림차순
    -> 잘 와닿지 않음
4. 그러면 정렬 -> x나 y 거리가 D 이상이면 거르기? 
  -> 얼마나 의미가 있을진 모르겠지만, 무의미하진 않아 보임
  -> y 기준부터 시도?
5. 생각해보니 각 편대는 D 이상의 거리임을 보장한다
  -> 전체 드론을 축 기준으로 불필요한 내용 자르고
  -> 편대별로 따로 저장해서 비교하는 것이 아닌 전체를 저장하는 배열을 만들어, y 기준 정렬을 한 이후 y 거리가 D 이상이 되면 다음 비교시작하는 방식?
