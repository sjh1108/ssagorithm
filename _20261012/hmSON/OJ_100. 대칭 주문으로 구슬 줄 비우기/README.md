# OJ_100. 대칭 주문으로 구슬 줄 비우기
연속한 회문 구간을 한 번에 제거하는 주문이 존재할 때, 주어진 줄 전체를 비우는 최소 주문 횟수를 구해야 함

가운데의 구슬 줄을 제거하면 양 옆이 붙기 때문에 어떤 순서로 제거하느냐에 따라 결과가 바뀜<br>
따라서 구간을 쪼개는 모든 방법을 비교해야 하며 이를 구간 DP를 이용해 수행할 것

구간 DP를 이용한 팰린드롬의 핵심 로직은 2차 반복문 내에서 현재 처리하는 양 끝이 같은지 비교하고, 그 결과에 따라 동작해야 한다는 것


## 1. 상태 정의 - 구간 DP
> **`dp[l][r]` = 구간 `[l, r]`의 구슬을 전부 제거하는 최소 주문 횟수**

작은 구간부터 채워 올라가면 큰 구간을 계산할 때 이미 확정된 하위 구간의 답을 활용할 수 있음<br>
구간 1은 각각의 구슬 그 자체로 회문이므로 `dp[i][i] = 1`로 초기화


## 2. 기본 선택지 - 두 구간으로 분할
현재 처리하는 구간을 둘로 쪼개 각각 처리하는 경우

> $$dp[l][r] = \min(dp[l][r],\ dp[l][k] + dp[k+1][r])$$

분할 지점 `k`를 구간 내 모든 위치에 대해 시도하고 그 중 최솟값을 취함. 구간 크기가 4라면 (1,3), (2,2), (3,1)로 나눈 세 경우를 비교하게 됨.


## 3. 조건부 선택지 - 양 끝이 같은 색일 경우
양 끝 구슬의 색이 같으면($c_l = c_r$) 가운데 구간의 처리 횟수를 그대로 이어받는 선택지가 추가됨

> $$dp[l][r] = \min(dp[l][r],\ dp[l+1][r-1])$$

**가운데 구간을 어떤 식으로 처리하든 마지막 주문 시점에 양 끝 구슬을 함께 묶어도 회문이 성립하기 때문**
<br>
단, 이것이 항상 최선의 선택은 아니므로 기존 선택지의 최소값과 비교 필수


### 3-1. 경계 처리
구간 길이가 2인 경우 양 끝 구슬의 색이 같아도 참조할 가운데 구간이 없음<br>
따라서 양 끝이 같은 길이 2 구간은 그 자체로도 회문이므로 1을 직접 대입


## 4. 순회 순서
구간 DP의 순회 순서는 다음과 같이 관리해야 함

```java
for(int i=1; i<n; i++)        // i = 구간 간격 (크기 - 1)
    for(int j=0; j<n-i; j++)  // j = 구간 시작 위치
        for(int k=0; k<i; k++) // k = 분할 지점
```

바깥 루프가 **구간 크기**를 관리해야 작은 구간이 먼저 확정되고 큰 구간에서 작은 구간을 참조할 수 있음


## 5. 복잡도
- 상태 수 : 구간의 양 끝 조합이므로 $O(N^2)$
- 전이 : 각 상태마다 분할 지점을 모두 시도하므로 $O(N)$

전체 $O(N^3)$. `N = 500` 기준 약 $1.25 \times 10^8$ 연산이며, 내부 연산이 단순 비교·덧셈이라 6초 제한 안에 들어옴.

공간 복잡도는 DP 테이블로 $O(N^2)$.
