# OJ 122 ~ 124

단방향 노선으로 이어진 정류장에서 정상까지의 비용을 구하는 세 문제<br>
**단방향 그래프의 역방향 설계** -> **배차 간격이 존재하는 그래프의 다익스트라** -> 두 문제의 혼용 형태로 구성됨


## 122. 정상까지 몇 번 갈아타나

**요구사항** : 모든 정류장에서 정상 `N` 까지의 최소 탑승 횟수

정류장마다 BFS를 돌리면 `O(NM)`

> **노선 방향을 모두 뒤집고 정상을 출발점으로 BFS 한 번**

비용이 전부 1이므로 BFS로 충분하고, 한 번의 순회로 `N` 개의 답이 전부 나옴<br>
갱신되지 않은 정류장은 그대로 `-1`


## 123. 배차 간격이 있는 케이블카

**요구사항** : 정류장 1에서 시각 0에 출발해 정상에 도착하는 가장 이른 시각

### 직전 문제와의 차이 : 비용이 고정이 아님
노선마다 첫 출발 `s`, 간격 `p`, 소요 시간 `w` 가 주어짐

> **같은 노선이라도 도착 시각에 따라 대기 시간이 달라져 실제 비용이 변함**

비용이 균일하지 않으므로 BFS 대신 **다익스트라**

### 탑승 시각 계산
현재 시각 이상인 첫 출발을 **올림 나눗셈**으로 직접 구함

```java
long k = (current - first + interval - 1) / interval;
return first + k * interval + moveTime;
```

정확히 출발 시각에 도착한 경우가 분기 없이 흡수됨


## 124. 마지막 케이블카를 놓치지 마라

**요구사항** : 행사 시각 `T` 기준, 등산객 `Q` 명 각각이 출발 전 머물 수 있는 가장 늦은 시각

### 차이 (1) : 질의가 Q개
등산객마다 다익스트라를 돌리면 25억회

122의 방향 뒤집기를 재사용해 **정상 기준 역방향 다익스트라 한 번으로 전처리**<br>
이후 각 질의는 배열 참조로 끝남

### 차이 (2) : 최소화에서 최대화로
"가장 늦은 출발 시각"을 최대화해야 하므로 다익스트라가 통째로 뒤집힘

- 우선순위 큐 정렬이 **내림차순**
- 갱신 조건이 **`더 크면`**
- 초기값이 **`-1`**

### 탑승 시각의 역산
123의 올림과 대칭으로, 도착 시각에서 역산해 `current - w` 이하인 마지막 출발을 **내림**으로 구함

```java
long expected = current - moveTime;
if(expected < first) return -1;

long passed = (expected - first) / interval;
return first + (passed * interval);
```

초기값 `-1` 이 "도달 불가"와 "어떤 출발 시각보다 작은 값" 두 역할을 겸해,<br>
노선을 탈 수 없을 때의 `-1` 이 갱신 조건에서 자연히 걸러지고 출력도 별도 처리가 불필요


## 시리즈 정리
