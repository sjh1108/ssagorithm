# 문제 해석
K개의 꾸러미를 구성하는 문제
1. 모든 부품을 넣어야 함
2. 가장 무거운 꾸러미 무게의 최솟값

# 풀이
## 완전 탐색
전체 부품을 각 꾸러미에 넣은 경우를 연산함
(순열 형식)

## 가지치기
1. 이미 연산된 최솟값보다 꾸러미의 무게가 더 무거워지는 경우는 연산하지 않는다.
2. 무게 내림차순으로 정렬 시 1의 가지치기가 더 효율적일 것
3. 절대적인 최솟값이 존재함
  * 전체 무게의 평균과 가장 무거운 부품의 무게 중 더 무거운 것
  * 해당 값 도출 시 더 이상 진행할 필요가 없음
4. 꾸러미의 무게가 가벼운 순부터 채워 넣으면 1의 경우를 연산하기 쉬울 것
5. 각 부품을 연산할 때 같은 무게인 꾸러미는 여러 번 연산할 이유가 없음
