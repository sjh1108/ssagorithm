# 40. 마나 순환로


## 문제 분석
각 동전마다 최대 $c_i$개 사용할 수 있고 이 동전들을 한도 내에서 골라 조합하여 특정 합을 만들 수 있는지 요구하고 있습니다. 조합을 통해 만들 수 있는 모든 금액 조합의 수와 합계를 구하는 문제입니다.
<br>
전형적인 배낭 채우기(Knapsack) 문제의 응용입니다. 각 동전을 최대 한 번만 사용하는 것이 배낭 채우기 문제의 기본형입니다. 따라서 이 문제 또한 각 동전을 낱개로 분류하여 문제를 풀어야 하지 않을까 싶지만 이는 불가능하다는 점을 이미 문제에서 경고하고 있습니다.

> 발굴된 동전의 총 개수 $c_i + c_2 + ... + c_M$은 $10^{11}$에 이를 수 있으므로, 동전을 낱개로 모두 늘어놓는 방법으로는 풀 수 없다.

각 동전의 수 $c_i$는 최대 $10^{11}$까지 주어질 수 있으며, 동전의 종류 $N$은 최대 `100`개까지 주어질 수 있으므로 이를 모두 낱개로 분류하는 것은 불가능합니다.

따라서 동전의 개수 및 분류를 다음 방법으로 최소화하여 연산 수를 줄일 필요가 있습니다.


### 1. 최대값 $S$를 초과할 정도로 필요하지는 않다
동전의 개수가 최대 $10^9$개로 주어진다 해도 $S$의 최대값은 `100,000`입니다. 동전의 가치가 `1`일 경우 필요한 최대 동전 개수는 `100,000`개이며 동전의 가치가 클 수록 필요한 최대 동전 개수도 감소합니다. 


### 2. 최대값 $S$보다 가치가 큰 동전은 필요 없다
이 점 또한 문제에서 이미 고지하였습니다.
> 액면가가 $S$보다 큰 종류도 주어질 수 있으며, 그런 동전은 한 개만 써도 금액이 $S$를 넘으므로 아무 도움이 되지 않는다.

$1$ 이상 $S$ 이하의 가치를 가진 조합을 찾는 것이 목적입니다. 동전 하나의 가치가 $S$보다 크다면 해당 동전은 취급하지 않습니다.


### 3. 이진 분할 : 동전들을 2의 제곱수 단위로 묶기
그럼에도 불구하고 각 동전을 낱개로 처리하는 것은 큰 연산 횟수를 요구할 것입니다. 따라서 ${1, 2, 4, ..., 2^x}$ 단위로 동전을 묶고 더 이상 묶을 수 없는 나머지 동전들도 하나의 묶음으로 취급합니다.<br>
예를 들어 어떤 동전의 개수가 13이라면 순서대로 $\{1, 2, 4\}$ 묶음을 만든 뒤 남은 `6`개도 하나의 묶음으로 만들어 $\{1, 2, 4, 6\}$로 동전을 묶을 수 있습니다. 

각 묶음 $b_j$에 동전의 가치 $v_i$를 곱한 값을 하나의 새 동전으로 취급하여 DP 점화식에 적용합니다. 상기한 묶음 순서대로 DP 점화식에 적용하면 단 4번의 반복만으로 1~13 조합을 모두 확인한 것과 동일한 결과를 얻을 수 있습니다. 


## 설계 및 구현


### 1. 상태 정의 : boolean 타입 DP 배열
```java
static boolean[] dp;
```
```java
dp = new boolean[max+1];
dp[0] = true;
```

다른 동전 조합으로 같은 금액 조합을 구성하는 경우에 대해 문제에서는 다음과 같이 취급합니다.
> 같은 금액을 여러 방법으로 만들 수 있어도 한 번만 센다.

따라서 특정 금액을 만들 수 있는 조합의 수는 알 필요 없습니다. 그저 한 번이라도 만들 수 있는지만 알면 됩니다. 따라서 `boolean` 타입 배열만으로도 문제를 해결할 수 있습니다.


### 2. 유효 개수 상한 적용
```java
int val = Integer.parseInt(st.nextToken()); // 동전의 가치
int cnt = Integer.parseInt(st.nextToken()); // 동전의 개수

if(cnt > max / val) cnt = max / val; // 최대값 max를 초과할 정도의 동전은 필요 없음
```
동일한 동전을 모두 사용했을 때 `max`값을 초과하는 경우 잉여 가치 자원이 존재함을 의미합니다. 필요한 개수만 두고, 나머지는 전부 버립니다.


### 3. 이진 분할과 DP
```java
int p = 1;
while(p <= cnt) {
    applyDP(p * val); // 동전 묶음의 가치 = 기존 동전의 가치 * 묶음의 동전 개수
    cnt -= p; // 사용한 동전은 차감
    p <<= 1; // 묶음 크기 2배로 증가
}

if(cnt > 0) applyDP(cnt * val);
```
동전 `1`개부터 시작하여 $\{1, 2, 4, ...\}$ 순서대로 개수를 빼 나가며, 각 묶음의 **개수 x 액면가**를 하나의 새 동전으로 취급하고 이를 DP에 적용합니다. 2의 거듭제곱으로 더 이상 뺄 수 없다면 남은 나머지를 마지막 묶음으로 한 번 더 적용합니다.


### 4. 점화식
```java
static void applyDP(int v) {
    for(int j=max; j>=v; j--) {
        dp[j] = dp[j] || dp[j-v];
    }
}
```
- 최대값 S부터 시작하여 현재 다루는 동전 묶음의 가치까지 1씩 감소시키면서 점화식을 적용합니다. 증가하는 반복문으로 DP를 수행할 경우 동일한 동전이 무한으로 적용되는 문제를 유발할 수 있습니다. 따라서 역순으로 처리하여 이를 방지합니다.<br>
- 점화식에서 필요로 하는 정보는 2가지입니다. 두 조건 중 하나라도 성립하면 특정 금액 `j`를 구성할 수 있다고 판단합니다.
    1. 이미 다른 조합으로 현재 가치 `j`를 구성한 적이 있는가?
    2. 주어진 동전 묶음의 가치를 더함으로써 현재 가치 `j`를 구성할 수 있는가?
- 이를 위해 초기화 단계에서 `dp[0]`을 `true`로 처리해 두어 아무것도 없는 상황에 동전을 추가하는 경우도 `true`로 적용되도록 하였습니다.
