# 룬 석판의 공명 구간
## 풀이: 누적 XOR + HashMap

### 1. 접근 방법

연속 구간의 XOR 값이 K가 되는 구간의 개수를 구하는 문제

처음에는 이중 반복문으로 모든 구간을 확인하는 방법을 생각했고, 그렇게 풀었었다. 근데 태그에 해시맵이 있어서 다른 풀이 방법을 알아보았다.

이전엔 이중 for문으로 O(N^2) 이를 개선하기 위해 **누적 XOR과 HashMap을 활용하여 O(N)에 해결**할 수 있다.

솔직히 이런 고능한 풀이는 처음에 떠오르지 않을거같다.

### 2. 핵심 아이디어

** 누적 XOR을 이용한 구간 계산**

XOR은 같은 값을 두 번 연산하면 0이 되는 성질이 있다.

- `A ^ A = 0`
- `A ^ 0 = A`

따라서 현재 누적 XOR과 이전 누적 XOR을 연산하면, 이전 구간의 값이 제거되어 두 위치 사이의 구간 XOR을 구할 수 있다.

`구간 XOR = 현재 누적 XOR ^ 이전 누적 XOR`

** XOR이 K가 되는 이전 누적 XOR 찾기**

구간 XOR이 K가 되어야 하므로 다음 관계가 성립한다.

`현재 누적 XOR ^ 이전 누적 XOR = K`

이를 변형하면 다음과 같다.

`이전 누적 XOR = 현재 누적 XOR ^ K`

즉, **현재 누적 XOR에서 K를 만들기 위해 필요한 이전 누적 XOR 값은 `xor ^ K`이다.**

이 값이 이전에 여러 번 등장했다면, 각 위치에서 시작하는 서로 다른 구간을 만들 수 있다. 따라서 해당 값의 등장 횟수만큼 정답에 더하면 된다.

** HashMap을 이용한 최적화**

HashMap에 이전 누적 XOR 값과 등장 횟수를 저장한다.

- Key: 누적 XOR 값
- Value: 해당 값의 등장 횟수

현재 위치를 구간의 끝점으로 생각하고, 이전 누적 XOR 중 `xor ^ K`가 등장한 횟수를 조회한다.

각 구간은 끝점이 정해져 있으므로, 순회하면서 정답을 누적해도 중복으로 계산되지 않는다.

### 3. 알고리즘

1. HashMap에 초기 누적 XOR인 `(0, 1)`을 저장한다. 이는 첫 번째 원소부터 시작하는 구간을 누락하지 않기 위함이다.
2. 배열을 순회하며 현재 원소를 누적 XOR에 반영한다.
3. HashMap에서 `xor ^ K`의 등장 횟수를 조회하여 정답에 더한다.
4. 현재 누적 XOR의 등장 횟수를 HashMap에 갱신한다.
5. 모든 원소를 처리한 후 정답을 출력한다.

**주의:** 현재 누적 XOR을 저장하기 전에 정답을 먼저 계산해야 한다. 그렇지 않으면 K가 0인 경우 현재 누적 XOR을 자기 자신과 비교하여 빈 구간까지 세게 된다.

### 4. 시간 및 공간 복잡도

- **시간 복잡도: O(N)** — 배열을 한 번 순회하며 HashMap 조회 및 갱신을 평균 O(1)에 수행한다.
- **공간 복잡도: O(N)** — 누적 XOR 값의 등장 횟수를 HashMap에 저장한다.

# 단어 변환
## 풀이: BFS (너비 우선 탐색)

### 1. 접근 방법

시작 단어에서 목표 단어까지의 최소 변환 횟수를 구하는 문제이다.

한 번에 한 글자만 변경할 수 있으며, 최소 변환 횟수를 구해야 하므로 **BFS를 활용**하였다.

### 2. 핵심 아이디어

- 현재 단어와 한 글자만 다른 단어를 찾아 큐에 삽입한다.
- BFS는 변환 횟수가 적은 순서대로 탐색하므로, 목표 단어에 처음 도달했을 때 최소 변환 횟수를 보장한다.
- `visited` 배열을 사용해 중복 탐색을 방지한다.

### 3. 알고리즘

1. 시작 단어와 변환 횟수 0을 큐에 삽입한다.
2. 큐에서 단어를 꺼내 목표 단어인지 확인한다.
3. 방문하지 않았고 한 글자만 다른 단어를 찾아 변환 횟수를 1 증가시켜 큐에 삽입한다.
4. 목표 단어에 도달하면 변환 횟수를 반환하고, 도달하지 못하면 0을 반환한다.

### 4. 시간 및 공간 복잡도

- **시간 복잡도: O(N² × L)** — N개의 단어를 탐색하며 각 단어를 최대 N개와 비교하고, 비교에 L만큼 소요된다.
- **공간 복잡도: O(N)** — BFS 큐와 방문 배열을 사용한다.

*N: 단어 개수, L: 단어 길이*
