## 목표

마지막 행까지 내려갔을 때 얻을 수 있는 최대 누적 점수를 구한다.

## 상태

```text
dp[r][c]
= r행까지 내려왔고 마지막으로 c열을 선택했을 때의 최대 누적 점수
```

전체 최대값 하나만 저장하면 그 값이 어느 열에서 나왔는지 알 수 없다.
같은 열을 연속해서 선택할 수 없으므로 마지막으로 선택한 열별 최대 누적 점수를 저장한다.

## 전이

현재 `c`열과 다른 이전 행의 세 열 중 가장 큰 누적 점수를 선택하고 현재 칸의 점수를 더한다.

```text
dp[r][c]
= land[r][c] + max(dp[r - 1][p])
  단, p != c
```

## 종료 조건

마지막 행인 `land.length - 1`행까지 계산하면 종료한다.
마지막 행의 네 `dp` 값 중 최댓값을 반환한다.

## 초기화

첫 번째 행에는 이전 행이 없으므로 각 칸의 점수를 그대로 넣는다.

```text
dp[0][c] = land[0][c]
```

## 탐색 공간 및 복잡도

```text
상태 개수: N × 4
상태 하나의 계산: 이전 열 3개 확인
전체 연산: N × 4 × 3 = 12N
시간 복잡도: O(N)
공간 복잡도: O(N × 4) = O(N)
```

## 손으로 실행해보기

```text
입력:
[1, 2, 3, 5]
[5, 6, 7, 8]
[4, 3, 2, 1]

첫 번째 행:
[1, 2, 3, 5]

두 번째 행:
[10, 11, 12, 11]

세 번째 행:
[16, 15, 13, 13]

마지막 행의 최댓값은 16이다.
```

## 풀이 후 배운 점

완전탐색은 첫 행에서 4개, 이후 각 행에서 3개의 선택지가 생겨 `4 × 3^(N - 1)`만큼 증가한다.

이전 행의 전체 최대값 하나만 저장하면 마지막으로 선택한 열 정보가 사라진다.
미래의 선택에 필요한 마지막 열을 상태에 포함하고, 같은 상태에 도착한 여러 경로 중 최대 누적 점수만 남기면 DP로 경우의 수를 줄일 수 있다.
