# 28. 주괴 K개씩 합치기 풀이 

## 문제 분석
대장장이는 정확히 K개의 주괴를 선택하여 하나의 새 주괴로 합쳐야 합니다. 새 주괴를 만드는 데 사용된 K개의 주괴의 무게 합이 제련 비용이자 새 주괴의 무게입니다.

그러나 정확히 K개씩 묶어 제련해야 하기 때문에 주어지는 N개의 주괴 전체를 하나로 합치는 것이 불가능할 수 있습니다. 이에 대비하여 무게가 0인 가상의 "가짜 주괴"를 필요한 개수만큼 만들어 사용해야 합니다.

또한 위 과정에서 제련에 드는 비용의 합을 최소화해야 합니다. 위 조건을 충족하기 위해 필요한 만큼의 가짜 주괴를 추가하면서 제련 비용을 최소화하기 위해 다음의 2가지 접근이 요구된다고 보았습니다.

### 1. 무거운 주괴부터 제련하면 그만큼 비용이 곱으로 증가한다.
- 무게가 1인 주괴를 사용하여 만들어진 새 주괴를 2번 더 제련 과정에 사용하면 무게가 1인 주괴를 제련에 총 3번 사용하게 되어 3의 비용이 들게 됩니다.

- 마찬가지로 무게가 10인 주괴를 사용하면 같은 경우에 대해 30의 비용이 들게 됩니다.

- **즉, 무게가 가벼운 주괴부터 제련에 사용할 수록 가중되는 전체 비용이 감소할 것이라는 가정입니다.**

### 2. K개의 주괴를 묶는 게 아니라, K-1개의 주괴를 다른 한 주괴에 붙이는 개념으로 바라본다.
- 만약 `K = 4`인 경우 매 제련마다 4개의 주괴가 하나의 새 주괴로 합쳐집니다. 그 과정에서 주괴의 개수는 3개씩 줄어듭니다.
- 즉, `K = 4`인 경우 전체 주괴 수가 `1, 4, 7, 10, 13, ...`개일 때 가짜 주괴 추가 없이 하나의 주괴로 합칠 수 있게 됩니다.
- 이를 다음 공식으로 정리해볼 수 있습니다 -> `N = x(K-1) + 1 (if x > 2)`
- `K = 2`인 경우 가짜 주괴가 없어도 하나의 주괴로 합칠 수 있으므로 해당 공식이 적용되지 않습니다.

## 설계 및 구현
앞의 두 접근을 코드로 옮기면 처리 순서는 다음과 같습니다.

### 1. 필요한 가짜 주괴 수를 미리 확인
```java
if(k > 2 && n % (k-1) != 1) {
    int diff = (k - n % (k-1)) % (k-1);
    for(int i=0; i<diff; i++) pq.add(0L);
}
```
주괴 목록을 읽기 전에 필요한 가짜 주괴 수를 미리 파악하여 큐에 입력합니다.
`r = n % (k-1)`이라 할 때 `k ≡ 1 (mod k-1)`이므로 `(k - r) % (k-1)`은 `(1 - r) mod (k-1)`과 같습니다.
즉 이 값은 **전체 개수를 `x(K-1) + 1` 꼴로 만들기 위해 보충해야 하는 최소 개수**입니다.

`k == 2`인 경우는 `k-1 == 1`이라 어떤 `n`이든 조건을 만족하므로 가짜 주괴가 필요 없고,
`n % 1`은 항상 0이라 조건식이 오작동할 수 있으므로 `k > 2` 가드를 두었습니다.

### 2. 최소 힙
가벼운 주괴부터 제련해야 그만큼 큰 비용의 복제를 방지할 수 있으므로 가벼운 주괴부터 꺼낼 수 있도록 최소 힙(`PriorityQueue`)을 사용합니다.

제련으로 만들어진 새 주괴가 다시 다른 주괴들과 비교 대상이 되므로 힙 구조가 요구됩니다.

### 3. 우선순위 큐 크기가 1이 될 때까지 K개씩 꺼내서 합친다
```java
while(pq.size() > 1) {
    long val = 0;
    for(int i=0; i<k; i++) val += pq.poll();
    sum += val;
    pq.add(val);
}
```
큐에서 K개의 값을 꺼내 더한 값이 제련 1회의 비용이자 새 주괴의 무게입니다.
비용은 sum에 누적해두고, 새 주괴는 다시 큐에 넣어 제련 대상에 포함시킵니다.
미리 가짜 주괴를 필요한 수만큼 추가하여 초기에 사용되게끔 준비되어 있으므로 가짜 주괴는 초기 제련에 전부 소진됩니다.

## 복잡도
- 가짜 주괴 삽입 : 최대 `K-2`회 우선순위 큐 삽입이므로 `O(K log N)`
- 주괴 삽입 : `N`회 우선순위 큐 삽입이므로 `O(N log N)`
- 제련 반복 : 각 제련마다 `K`번 poll, `1`번 add이며 이를 `N / (K-1)`회 반복하므로 `O(N log N)`
