- 검증: 공식 예제 3개, 추가·경계 사례 4개, Floyd-Warshall 기준 풀이와 비교한 무작위 사례 250개 통과
- 코드: [합승_택시_요금.java](합승_택시_요금.java)

로컬 검증 결과이며, 프로그래머스 전체 채점 통과를 확인한 것은 아니다.

## 목표

두 사람이 `s`에서 함께 출발하여 각각 `a`, `b`에 도착할 때 필요한 최소 택시 요금을 구한다.
어느 지점 `i`까지 합승한 후 각자 이동할지 모든 지점을 후보로 확인한다.
`i = s`를 선택하면 처음부터 합승하지 않는 경우도 포함된다.

## 상태

```text
distA[i]    = a에서 i까지의 최단 요금
distB[i]    = b에서 i까지의 최단 요금
distcost[i] = s에서 i까지의 최단 요금
```

도로가 양방향이므로 `a → i`의 최단 요금은 `i → a`와 같고, `b`에 대해서도 마찬가지다.
따라서 세 출발점에서 구한 최단거리 배열만으로 모든 합승 종료 지점을 비교할 수 있다.

- 다익스트라의 현재 상태: 지점 `node.id`와 그곳까지의 누적 요금 `node.dist`
- 최단거리 기록: 각 실행 안의 `dist[]`
- 정답 누적값: 모든 합승 종료 지점에서 구한 총요금 중 최솟값 `answer`

인접 리스트에 있는 `Node.dist`는 도로 하나의 요금이고, 큐에 있는 `Node.dist`는 출발점부터의 누적 요금이다.
같은 클래스를 사용하지만 역할을 구분해서 읽어야 한다.

## 전이

`fares`의 각 도로를 양방향 인접 리스트에 저장한다.
다익스트라에서는 현재 지점과 연결된 다음 지점을 확인한다.

```text
nextCost = 현재까지의 누적 요금 + 다음 도로의 요금

nextCost < dist[다음 지점]이면:
dist[다음 지점] = nextCost
다음 지점과 nextCost를 우선순위 큐에 넣는다.
```

이 과정을 `a`, `b`, `s`에서 각각 한 번씩 실행한다.
이후 모든 지점 `i`에 대해 다음 값을 비교한다.

```text
총요금 = distcost[i] + distA[i] + distB[i]
answer = min(answer, 총요금)
```

공통 구간 `s → i`의 요금은 한 번만 더한다.

## 종료 조건

다익스트라 실행마다 우선순위 큐가 비면 종료하고 최단거리 배열을 반환한다.
큐에서 꺼낸 비용이 현재 `dist`보다 크면 오래된 정보이므로 건너뛴다.

세 번의 다익스트라와 모든 합승 종료 지점의 비교를 마친 뒤 `answer`를 반환한다.

## 초기화

- 지점 번호가 1부터 시작하므로 인접 리스트와 거리 배열의 크기는 `N + 1`이다.
- 다익스트라 호출마다 새로운 `dist[]`를 만들고 `Integer.MAX_VALUE`로 채운다.
- 이번 출발점만 거리 0으로 설정하여 큐에 넣는다.
- 전체 정답 `answer`는 `Integer.MAX_VALUE`로 시작한다.

출발점이 달라질 때 이전 실행의 거리 값을 재사용하지 않는다.

## 탐색 공간 및 복잡도

`V`는 지점 수, `E`는 양방향 도로 정보의 수다.

```text
다익스트라: 3회
합승 종료 후보: V개
후보 하나의 총요금 계산: O(1)

시간 복잡도: O(3 × (V + E) log V + V)
           = O((V + E) log V)
공간 복잡도: O(V + E)
```

### 도달할 수 없는 지점의 처리

문제는 `s`에서 `a`, `b`로 가는 경로는 보장하지만 모든 지점의 연결을 보장하지는 않는다.
다른 연결 요소의 지점에서는 세 거리 모두 `Integer.MAX_VALUE`로 남는다.

원본은 이 값을 그대로 더한다. Java `int`에서 세 값을 더하면 오버플로로 `2147483645`가 된다.
이 문제에서는 유효한 후보의 총요금이 최대 `3 × 199 × 100000 = 59700000` 이하이므로 이 큰 값이 최솟값으로 선택되지는 않는다.
그래도 안전하게 일반화하려면 거리 중 하나라도 무한대인 후보는 합산 전에 제외하는 것이 좋다. 원본 로직은 수정하지 않았다.

## 손으로 실행해보기

```text
n = 4, s = 1, a = 3, b = 4
fares = [[1, 2, 2], [2, 3, 3], [2, 4, 4]]

지점 i:     1  2  3  4
distcost:   0  2  5  6
distA:      5  3  0  7
distB:      6  4  7  0
총요금:    11  9 12 13

합승 구간: 1 → 2, 비용 2
A 이동:   2 → 3, 비용 3
B 이동:   2 → 4, 비용 4

반환값: 2 + 3 + 4 = 9
```

`i = 1`의 총요금 11은 합승하지 않는 경우이고, `i = 2`에서 나누어 이동하는 것이 더 저렴하다.

## 풀이 후 배운 점

- 두 사람의 모든 이동 경로를 직접 조합하는 대신 합승 종료 지점을 선택하는 문제로 바꿀 수 있다.
- 양방향 그래프에서는 목적지에서 출발하는 다익스트라로 목적지까지의 거리도 구할 수 있다.
- 최단거리 세 배열을 구하면 후보 하나의 비용을 상수 시간에 계산할 수 있다.
- 도달 불가를 나타내는 값은 실제 비용이 아니므로 합산 전 별도로 처리하는 습관이 필요하다.
