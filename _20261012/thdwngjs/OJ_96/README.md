# [OJ]95_무기와 방패 한 벌

## 문제 해석 및 생각의 흐름
1. 보유한 돈으로 무기와 방어구를 구매해 갖출 수 있는 가장 높은 전투력을 연산하는 것
2. 두 종류를 정렬하는 것이 좋아보임
3. 근데 어떻게 정렬하지? 돈 기준? 전투력 기준?
4. 일단 "돈"이 기준이 되어야 함, 왜? 결국에 구매의 기준은 비용이기 때문
5. 그러면 둘 다 돈을 기준으로 정렬하면 높은 전투력은 어떻게 확인하지?
6. 그러면 일단 돈을 기준으로 정렬하고, 그 금액에서 갖출 수 있는 가장 높은 전투력을 미리 연산해두면 되겠구나
7. 근데 둘 다 연산할 필요는 없어 보이고 투포인터를 활용해서 더 이상 확인할 필요가 없는 부분은 건너뛰면 되겠다

## 구현
### 금액 기준 정렬
무기와 방어구 모두 금액을 기준으로 정렬한다.
금액이 같은 경우에 높은 전투력을 기준으로 건너뛰게 할 수 있어보이나, 이 문제에서는 과도한 구현이라고 생각되어 하지 않음
```java
Arrays.sort(weapon, (o1, o2) -> {
    if(o1[0] == o2[0]){
    return Integer.compare(o1[1], o2[1]);
    }
    return Integer.compare(o1[0], o2[0]);
});

Arrays.sort(armor, (o1, o2) -> {
    if(o1[0] == o2[0]){
    return Integer.compare(o1[1], o2[1]);
    }
    return Integer.compare(o1[0], o2[0]);
});
```

### 구간 최대값 연산
각 방어구의 금액에서 최대로 가질 수 있는 전투력을 연산함
```java
int[] max = new int[M];

max[0] = armor[0][1];
for(int i = 1; i < M; i++){
    max[i] = Math.max(max[i-1], armor[i][1]);
}
```

### 최대 전투력 연산
#### 무기별 순회
각 무기를 순회하며, 무기를 구매할 때 갖출 수 있는 방어구 중 가장 높은 전투력을 택함
이때, 무기와 방어구를 금액순으로 정렬하였으니
순회 과정에서 금액이 높아 갖출 수 없는 방어구는 다음 차례에서도 탐색할 필요가 없음
방어구 포인터를 사용해 탐색할 필요가 없는 방어구는 탐색하지 않음

#### 최대값 배열
최대값 배열을 활용해 불필요한 탐색을 줄임
최대값 배열을 사용하지 않는다면, 방어구 배열을 매번 순회해야함
```java
for(int i = 0; i < N; i++){
    long p = weapon[i][0];
    long a = weapon[i][1];

    while(armor[ap][0] + p > B && ap > 0){
    ap--;
    }

    if(armor[ap][0] + p <= B){
    sum = Math.max(sum, max[ap] + a);
    }
}
```

## 구현 실수
### 구간 최대값을 연산했으나 사용하지 않았음
작성한 코드
```java
sum = Math.max(sum, armor[ap][1] + p);
```
의도한 코드
```java
sum = Math.max(sum, max[ap] + p);
```


### 전투력끼리 더해야 하는데 전투력 + 비용을 연산함
작성한 코드
```java
sum = Math.max(sum, max[ap] + p);
```
의도한 코드
```java
sum = Math.max(sum, max[ap] + a);
```
