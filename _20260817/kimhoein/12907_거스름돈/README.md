# 문제 링크/제목

- 제목: 거스름돈
- 링크: https://school.programmers.co.kr/learn/courses/30/lessons/12907
- 진행 상태: 완료

## 내가 이해한 문제

- 손님에게 `n`원을 거슬러 줄 수 있는 조합의 수를 구한다.
- 같은 동전 구성은 동전을 선택한 순서가 달라도 하나의 조합으로 계산한다.

## 상태

- `i`: 현재 처리하고 있는 `money`의 인덱스
- `j`: 현재 만들려고 하는 금액
- `dp[j]`: 지금까지 바깥 반복문에서 처리한 동전 종류들만 사용해서 `j`원을 만드는 조합의 수

바깥 반복문이 시작되기 전 `dp`에는 이전 동전까지 사용한 결과가 저장되어 있다.
현재 동전의 처리가 끝나면 `dp`에는 현재 동전까지 사용한 결과가 저장된다.

## 전이

현재 동전 `money[i]`를 사용해서 `j`원을 만드는 경우를 추가한다.

```text
dp[j] = (dp[j] + dp[j - money[i]]) % 1,000,000,007
```

`j`를 작은 금액부터 증가시키므로 현재 동전을 여러 번 사용할 수 있다.

## 제약

- 거슬러줘야 하는 금액 `n`과 정확히 일치해야 한다.
- 각 화폐는 무한히 사용할 수 있다.
- 정답은 `1,000,000,007`로 나눈 나머지를 반환한다.

## 목표

주어진 동전들을 사용해 `n`원을 만드는 조합의 수를 구하고, 그 값을 `1,000,000,007`로 나눈 나머지를 반환한다.

## 초기화

- 크기가 `n + 1`인 `dp` 배열을 생성한다.
- `dp[0] = 1`로 초기화한다.
- 나머지 `dp` 값은 `0`으로 시작한다.

`dp[0] = 1`은 아무 동전도 사용하지 않고 `0`원을 만드는 빈 조합 한 가지를 의미한다.

## 내 풀이 방향

크기가 `n + 1`인 `dp` 배열을 생성하고 `dp[0] = 1`로 초기화한다.

동전 종류를 바깥 반복문에서 하나씩 처리한다.
내부 반복문에서는 `0`원부터 `n`원까지 확인하고, 현재 동전보다 작은 금액은 건너뛴다.

각 금액에서 다음 점화식을 사용한다.

```text
dp[j] = (dp[j] + dp[j - money[i]]) % 1,000,000,007
```

모든 동전을 처리한 뒤 `dp[n]`을 반환한다.

## 탐색 공간 및 복잡도

- `n`: 거슬러줘야 하는 금액
- `m`: 화폐 종류의 수, `money.length`

바깥 반복문은 화폐 종류만큼 `m`번 실행한다.
내부 반복문은 `0`원부터 `n`원까지 확인하므로 `n + 1`번 실행한다.

```text
전체 반복 횟수: m × (n + 1)
시간 복잡도: O(m × n)
공간 복잡도: O(n)
제한 안에서 가능한가: 가능
```

## 막힌 부분

DP 점화식을 세우기가 힘들었다.
`dp[0] = 1`이 왜 1인지 알지 못했다.
