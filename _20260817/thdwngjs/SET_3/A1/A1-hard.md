# 가장 조용한 통신 경로 해설

## 문제 요약

가중치 있는 무방향 그래프에서 질의 $(u, v)$마다 "경로에 쓰인 간선 가중치의 최댓값"을 최소로 만드는 값(최소 병목)을 구한다. 같은 정점끼리면 $0$, 이어지지 않으면 $-1$이다.

## 관찰

질의 하나를 그대로 푸는 방법부터 생각해 보자. 답 후보를 하나 정해 놓고 "잡음이 그 값 이하인 케이블만 남겼을 때 $u$와 $v$가 이어지는가"를 물으면 되니, 값에 대한 이분탐색 + BFS로 한 질의를 $O((N + M)\log M)$에 처리할 수 있다. 그런데 질의가 $200{,}000$개다. $2 \times 10^5 \times 5 \times 10^5$은 시작도 못 한다. 다익스트라 변형(거리 갱신을 합 대신 최댓값으로)을 질의마다 돌려도 마찬가지다. 질의를 하나씩 독립적으로 푸는 순간 끝이다.

여기서 두 가지가 보인다.

**관찰 1. 답은 "임계값"이다.** 잡음이 $x$ 이하인 케이블만 남긴 그래프를 $G_x$라고 하자. $x$가 커질수록 케이블은 추가되기만 하고 절대 사라지지 않는다. 즉 $u$와 $v$가 $G_x$에서 이어지는지 여부는 $x$에 대해 단조롭다. 질의 $(u,v)$의 답은 **$u$와 $v$가 같은 컴포넌트에 처음 들어가는 순간의 $x$**다. 그러니 케이블을 잡음 오름차순으로 한 개씩 넣으면서 연결성을 키워 나가면, 모든 질의의 답이 "그 질의가 연결되는 순간"에 한 번씩 확정된다. 질의를 미리 전부 읽어 두는 오프라인 처리로 바꿀 수 있다는 뜻이다.

**관찰 2. 연결성은 유니온 파인드로만 관리하면 된다.** 케이블을 추가하기만 하므로 삭제가 없다. 문제는 "지금 합쳐진 컴포넌트 안에 답이 확정된 질의가 있는지"를 어떻게 싸게 찾느냐다. 합칠 때마다 남은 질의를 전부 훑으면 $O(MQ)$로 되돌아간다.

## 풀이

관찰 2의 마지막 문제는 **각 컴포넌트에 "그 컴포넌트에 걸쳐 있는 질의 id 집합"을 매달아 두는 것**으로 풀린다.

준비 단계에서 질의 $i = (u, v)$를 정점 $u$의 집합과 정점 $v$의 집합에 각각 넣는다. 질의 하나가 원소 두 개로 쪼개져 양쪽 끝에 놓이는 셈이다. 이제 컴포넌트 $A$와 $B$가 잡음 $w$짜리 케이블로 합쳐질 때, $A$의 집합과 $B$의 집합에 **같은 id가 동시에 들어 있다면** 그 질의의 두 끝점이 지금 막 한 덩어리가 된 것이다. 답은 $w$로 확정하고 그 id를 지운다. 한쪽에만 있는 id는 그냥 합친 집합으로 옮긴다.

집합 병합을 그냥 하면 큰 집합을 매번 복사하게 되니, **작은 집합을 큰 집합에 부어 넣는다**(small to large). 원소 하나가 옮겨질 때마다 그 원소가 속한 집합의 크기가 최소 두 배가 되므로, 원소 하나가 옮겨지는 횟수는 $\log$ 번을 넘지 않는다. 처음 원소가 $2Q$개니 전체 이동은 $O(Q \log Q)$다.

```python
if len(a) < len(b):     # a 가 항상 큰 쪽
    a, b = b, a
for qid in b:
    if qid in a:        # 양쪽에 다 있다 = 지금 이 케이블로 처음 이어졌다
        ans[qid] = w
        a.discard(qid)
    else:
        a.add(qid)
```

컴포넌트를 대표하는 정점은 유니온 파인드의 루트를 쓴다. 주의할 점은 **집합 병합 기준(집합 크기)과 유니온 파인드 병합 기준(컴포넌트 크기)이 별개**라는 것이다. 어느 쪽이 루트가 되든 합쳐진 집합을 새 루트에 다시 매달아 주면 된다.

공개 샘플로 따라가 보자. 케이블을 잡음 오름차순으로 정렬하면 $(1,3,1), (4,5,2), (1,2,3), (3,4,4), (2,3,5), (2,5,6), (5,6,7)$이다. 질의는 $q_0 = (2,5)$, $q_1 = (1,6)$, $q_2 = (2,3)$, $q_3 = (4,4)$이고, $q_3$은 두 정점이 같으니 읽는 즉시 $0$으로 답하고 집합에 넣지 않는다. 시작 집합은 정점 1에 $\{1\}$, 2에 $\{0, 2\}$, 3에 $\{2\}$, 5에 $\{0\}$, 6에 $\{1\}$이다.

| 케이블 | 하는 일 | 합친 컴포넌트의 집합 |
|---|---|---|
| $w=1$, (1,3) | 겹치는 id 없음 | $\{1, 2\}$ |
| $w=2$, (4,5) | 겹치는 id 없음 | $\{0\}$ |
| $w=3$, (1,2) | id 2가 양쪽에 있다 → $ans_2 = 3$ | $\{0, 1\}$ |
| $w=4$, (3,4) | id 0이 양쪽에 있다 → $ans_0 = 4$ | $\{1\}$ |
| $w=5$, (2,3) | 이미 같은 컴포넌트, 건너뜀 | — |
| $w=6$, (2,5) | 이미 같은 컴포넌트, 건너뜀 | — |
| $w=7$, (5,6) | id 1이 양쪽에 있다 → $ans_1 = 7$ | $\{\}$ |

답은 순서대로 $4, 7, 3, 0$이고 지문 예시와 같다. 케이블을 다 넣었는데도 집합에 남아 있는 id는 두 끝점이 끝내 이어지지 않은 질의이므로 $-1$이다. 답 배열을 $-1$로 초기화해 두면 따로 처리할 일이 없다.

## 복잡도

시간: $O(M \log M + Q \log Q \cdot \alpha(N))$.
- 케이블 정렬이 $O(M \log M)$. 이 문제의 실질적인 병목이다.
- 유니온 파인드 연산은 경로 압축 + union by size로 $O(\alpha(N))$이고, 케이블마다 두 번씩 부르므로 $O(M \alpha(N))$.
- 집합 원소 이동은 small to large 덕분에 전체 $O(Q \log Q)$이며, 이동 한 번마다 해시 집합 연산 몇 번이 붙는다.

공간: $O(N + M + Q)$. 질의 집합에 들어가는 원소가 처음 $2Q$개이고 병합해도 총량은 늘지 않는다.

## 구현 노트

- **잡음은 `long`이다.** $w \le 10^{12}$라 `int`에 넣으면 그 자리에서 값이 망가진다. 답을 담는 배열, 출력, 비교 모두 64비트로 통일한다.
- 자바에서 간선 정렬은 비교자를 쓰는 대신 $w$와 간선 번호를 `long` 하나에 담아 `(w << 19) | i`로 만들고 `Arrays.sort(long[])`로 정렬하면 편하다. $w < 2^{40}$, $M < 2^{19}$이므로 63비트 안에 들어간다. `Long[]`을 비교자로 정렬하면 박싱 때문에 훨씬 느려진다.
- **find는 반복문으로 짠다.** 사슬 모양 입력에서 재귀 find는 깊이 $200{,}000$까지 내려갈 수 있어 스택 오버플로가 난다. 경로 압축을 두 번 훑는 방식(루트 찾기 → 다시 내려오며 부모를 루트로)으로 쓰면 재귀가 필요 없다.
- $u = v$인 질의는 집합에 **넣으면 안 된다**. 같은 정점에 같은 id를 두 번 넣는 순간 집합은 원소 하나로 처리하므로 영영 답이 확정되지 않고 $-1$이 나온다. 읽는 즉시 $0$으로 답하고 넘어간다.
- 답이 확정된 id는 큰 집합에서도 지운다. 안 지워도 답 자체는 맞지만 집합이 계속 커져 병합 비용만 늘어난다.
- 이 문제의 검증기는 완전히 다른 길로 간다. 크루스칼로 최소 신장 숲을 만든 뒤 희소 배열로 두 정점의 트리 경로 위 최대 간선을 구한다("최소 병목 경로의 값 = MST 경로의 최대 간선"이라는 성질). 정렬 순서를 내림차순으로 잘못 잡거나, 다중 간선 처리를 빠뜨리거나, 이미 같은 컴포넌트인 케이블에서 답을 덮어쓰는 구현은 두 풀이의 출력이 갈리면서 바로 걸린다.

## 흔한 실수

- 질의마다 이분탐색 + BFS, 또는 질의마다 최댓값 다익스트라를 돌린다. 질의가 $20$만 개라 어떤 상수 최적화로도 살아나지 않는다.
- 잡음을 `int`로 받는다. $10^{12}$는 32비트 범위 밖이고, 값이 뒤집히면 정렬 순서까지 어긋나 답이 크게 틀린다.
- small to large 없이 매 병합마다 작은 쪽이 아니라 항상 오른쪽 집합을 왼쪽으로 복사한다. 한쪽으로만 자라는 그래프에서 $O(Q^2)$가 되어 시간 초과가 난다.
- 컴포넌트가 나뉘어 있는 입력을 생각하지 않고 답 배열을 $0$으로 초기화한다. 이어지지 않는 질의에 $0$이 출력된다. 반대로 $-1$ 처리를 하면서 $u = v$ 질의까지 $-1$로 보내는 실수도 자주 나온다.
- 같은 두 관측소를 잇는 케이블이 여러 개 들어온다. 이미 같은 컴포넌트인 케이블을 만나면 반드시 건너뛰어야 하고, 여기서 답을 갱신하면 나중에 나오는 더 큰 잡음으로 답이 덮여 틀린다.
