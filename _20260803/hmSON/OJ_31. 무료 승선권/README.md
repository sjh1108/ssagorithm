# 31. 무료 승선권

## 문제 분석
여러 항구 섬 `N`개 중 본토와 정기선으로 이어진 항구 섬 `P`개가 출발점으로 주어지며, `P`개의 출발점 항구 중 아무 곳이나 하나 선택한 뒤 `N`번째 섬까지 이동할 때의 최소 요금과 사용해야 하는 무료 승선권의 개수를 구해야 합니다.<br>
**#30번 문제 "최소 요금 항로"** 처럼 이동 횟수를 함께 관리하는 다익스트라 문제와의 차별점은 **"무료 승선권"** 입니다.

여행자는 **무료 승선권 `K`장**을 가지고 있습니다. 항로를 한 번 탈 때마다 승선권을 한 장 사용할 수 있고, 사용하면 **그 항로의 요금을 반감**합니다. 즉, 승선권을 적절한 타이밍에 사용하여 `N`번 섬까지 이동할 때의 총 비용을 최소화해야 합니다.

동일한 경로를 이동하더라도 승선권을 사용하는 타이밍에 따라 총 비용이 달라질 수 있습니다.
이 문제를 해결하기 위해 다음과 같이 설계할 필요가 있다고 보았습니다.
- 1. 각 섬에 도달하기 까지의 최단 거리를 "승선권 사용 횟수"별로 각각 저장한다
- 2. 다음 섬으로 이동할 때마다 승선권을 쓰는 경우와 쓰지 않는 경우를 모두 확인한다

또, 본토와 이어진 항구 섬 목록 중 도착점인 N번 섬이 목록에 주어질 가능성이 존재하므로 이를 무시하지 않도록 유의해야 합니다.

## 설계 및 구현

### 0. `N`번 섬(도착점)이 본토와 직접 연결된 경우
```java
for(int i=0; i<port; i++) {
    int p = Integer.parseInt(st.nextToken()) - 1;
    if(p == v-1) {
        System.out.println("0 0");
        return;
    }

    q.add(new Node(p, 0, 0));
    Arrays.fill(dist[p], 0);
}
```

`N`번 섬이 본토와 직접 연결되었다는 말은 굳이 다른 섬과 항로를 경유할 필요가 없다는 의미입니다. 따라서 굳이 다익스트라까지 활용하면서 이를 증명할 필요가 없습니다.

### 1. 각 섬마다 승선권 사용 횟수별 도달 시의 최소 비용을 각각 저장
```java
dist = new long[v][k+1];
for(int i=0; i<v; i++) {
    Arrays.fill(dist[i], Long.MAX_VALUE);
}
```

`dist[섬 번호][승선권 사용 횟수]` 형태로 같은 섬의 승선권별 최소 비용을 따로 기록합니다. 0회(승선권 미사용)부터 `K`회(승선권 소진)까지 전부 기록할 필요가 있으므로 2차원 배열의 크기는 dist[v][k+1]로 잡았습니다.

### 2. 다음 섬으로 이동할 때 승선권을 쓰는 경우와 쓰지 않는 경우를 모두 확인
```java
for(int[] next : graph[cur.id]) {
    long discountCost = cur.cost + (next[1] / 2);
    if(cur.used < k && dist[next[0]][cur.used + 1] > discountCost) {
        dist[next[0]][cur.used + 1] = discountCost;
        q.add(new Node(next[0], discountCost, cur.used + 1));
    }

    long newCost = cur.cost + next[1];
    if(dist[next[0]][cur.used] > newCost) {
        dist[next[0]][cur.used] = newCost;
        q.add(new Node(next[0], newCost, cur.used));
    }
}
```

다음 섬을 탐색할 때 승선권을 쓰는 경우와 그렇지 않은 경우를 모두 확인합니다.
승선권을 사용하는 경우, 다음 섬으로 이동하는 항로 비용을 반감한 뒤 적용합니다.
단, 이미 `K`장의 승선권을 전부 소진했다면 추가로 승선권을 사용하는 경우는 확인하지 않습니다.

그렇지 않은 경우, 다음 섬으로 이동하는 항로 비용을 그대로 적용합니다.

## 복잡도
- **상태 수:** 섬마다 승선권 0~K장 → $O(NK)$
- **간선 완화:** 각 상태에서 인접 항로마다 두 전이 → $O(MK)$
- **우선순위 큐:** 갱신마다 $O(\log(NK))$

종합하면 전체 시간 복잡도는 $O(MK \log(NK))$이고, `K`가 최대 5로 작아 사실상 일반 다익스트라와 큰 차이가 없습니다.
공간 복잡도는 $O(NK + M)$입니다.
