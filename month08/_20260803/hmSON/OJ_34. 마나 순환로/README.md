# 34. 마나 순환로

## 문제 분석
특정 알고리즘을 요구하지 않는 대신, 철저하게 2차원 배열을 행렬 인덱스를 이용해 각 기능을 수행하고 관리해야 하는 단순 구현 및 시뮬레이션 문제입니다.<br>
매 턴마다 **확산 -> 회전 -> 정화** 세 단계를 지정된 순서대로 수행하고 이를 `T`턴간 반복하는 형태입니다.

주어지는 정원의 크기는 최대 `60 × 60`이며, 턴은 최대 `500`입니다. 매 턴마다 수행해야 하는 각 기능 모두 정원 전체를 한 번씩 훑는다고 하더라도 총 연산량에 큰 문제가 없으며 최적화보다는 철저하게 규칙을 수행하는 데 중점을 둔 문제라고 판단했습니다.

따라서 각 단계마다 유의해야 할 포인트를 미리 정리하는 것이 중요했습니다.
- **1. 확산 :** 모든 칸이 *동시에* 확산합니다. 따라서 한 칸의 마나 확산이 이루어지더라도 이것이 다른 칸의 확산 값에 영향을 주면 안됩니다.
- **2. 회전 :** 각 고리마다 방향이 다릅니다. 또, 각 고리를 1차원으로 펴는 과정과 돌리는 방향을 어떻게 로직으로 적용시킬 지 고민해야 합니다.
- **3. 정화 :** 각 행에서 최대값이 여러 칸에 존재한다면 **가장 왼쪽 칸**을 골라야 합니다.

## 설계 및 구현

### 1. 확산 : 임시 배열 활용으로 동시성 보장
```java
static void spread() {
    for(int i=0; i<r; i++) Arrays.fill(temp[i], 0);

    for(int i=0; i<r; i++) {
        for(int j=0; j<c; j++) {
            if(arr[i][j] < 5) continue;
            long val = arr[i][j] / 5;

            for(int k=0; k<4; k++) {
                int y = i + dy[k];
                int x = j + dx[k];
                if(y < 0 || y >= r || x < 0 || x >= c) continue;

                arr[i][j] -= val;
                temp[y][x] += val;
            }
        }
    }

    for(int i=0; i<r; i++) {
        for(int j=0; j<c; j++) {
            arr[i][j] += temp[i][j];
        }
    }
}
```

각 칸의 확산 과정에 인접 칸의 확산에 의해 받은 마나가 포함되면 안됩니다. 따라서 확산으로 얻게 되는 마나량은 별도로 저장할 필요가 있습니다. <br>
따라서 임시 배열 `temp[r][c]`가 확산에 의해 각 칸이 얻게 되는 마나량을 임의로 저장하고 `arr[r][c]`의 각 칸은 확산에 의해 잃은 값만 적용해둔 뒤, 모든 확산 과정이 종료되면 이를 기존 배열에 전부 합산하는 방식을 선택하였습니다.

### 2. 회전 : 고리를 1차원으로 펴서 덱(Deque)으로
```java
static void rotate() {
    Deque<Long> deq = new ArrayDeque<>();
    for(int i=0; i<Math.min(r, c) / 2; i++) {
        for(int j=i; j<c-1-i; j++) deq.addLast(arr[i][j]);
        for(int j=i; j<r-1-i; j++) deq.addLast(arr[j][c-1-i]);
        for(int j=c-1-i; j>i; j--) deq.addLast(arr[r-1-i][j]);
        for(int j=r-1-i; j>i; j--) deq.addLast(arr[j][i]);

        if(i%2 == 0) deq.addFirst(deq.pollLast());
        else deq.addLast(deq.pollFirst());

        for(int j=i; j<c-1-i; j++) arr[i][j] = deq.pollFirst();
        for(int j=i; j<r-1-i; j++) arr[j][c-1-i] = deq.pollFirst();
        for(int j=c-1-i; j>i; j--) arr[r-1-i][j] = deq.pollFirst();
        for(int j=r-1-i; j>i; j--) arr[j][i] = deq.pollFirst();
    }
}
```

정원의 고리를 1차원으로 바라보려면 각 고리마다 시작점과 끝점을 어느 곳으로 둘 지 일반화해야 합니다. 이 작업이 완료되면 고리를 다시 2차원 배열에 배치하는 과정 또한 동일하게 수행할 수 있습니다.<br>
고리의 회전 방향은 바깥 고리인 0번 고리를 기준으로 하여 고리의 번호 홀짝에 따라 결정합니다.
- 고리의 번호가 짝수라면 시계 방향으로 회전합니다. 덱의 마지막 값을 덱의 시작점으로 밀어넣습니다.
- 고리의 번호가 홀수라면 반시계 방향으로 회전합니다. 덱의 처음 값을 덱의 끝점으로 밀어넣습니다.

### 3. 정화 : 행별 최대값 순차 탐색
```java
static void discharge() {
    for(int i=0; i<r; i++) {
        int idx = -1;
        long max = -1;

        for(int j=0; j<c; j++) {
            if(arr[i][j] > max) {
                max = arr[i][j];
                idx = j;
            }
        }

        discharged += arr[i][idx] / 2;
        arr[i][idx] -= arr[i][idx] / 2;
    }
}
```

각 행마다 순차 탐색하여 최대값 칸을 찾습니다. 해당 단계에서 유의할 점은 동점이 존재하는 경우인데, 각 행의 왼쪽부터 탐색하면서 최대값이 갱신되는 경우에만 마나를 배출해야 할 칸의 번호를 갱신합니다. 이를 통해 자연스럽게 가장 왼쪽에 있는 최대값을 가진 칸의 인덱스를 가지게 됩니다.

배출량의 경우 각 행마다 `(최대값을 가진 칸의 마나량) / 2`이며 소수점은 버립니다. 따라서 의도치 않게 잘못된 값을 저장하지 않도록 마나를 배출한 뒤의 기존 칸도 `/2`를 적용하지 않고 `(기존 값) / 2`를 기존 값에서 빼야 한다는 점의 유의했습니다.

## 복잡도
- **한 턴:** 확산·회전·정화 모두 격자를 상수 번 훑으므로 $O(NM)$
- **전체:** `T`턴 반복 → $O(T \cdot NM)$

`60 × 60 × 500 ≈ 180만`에 상수배 수준이라 시간 제한 안에 넉넉히 들어옵니다.
공간 복잡도는 원본과 임시 배열로 $O(NM)$입니다.
