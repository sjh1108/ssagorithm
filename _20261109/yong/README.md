## 네트워크
단순 bfs/dfs 다만 주어지는 연결상태 인접리스트가 컴퓨터 번호가 아니라 연결됨 1, 연결되지 않음 0 으로 표현되어 있으므로
while문 내에서 다음 후보를 찾을때 따로 인덱스 두고 후보 탐색 해야함

## 태양광 단지의 가장 넓은 정상 구역
직사각형을 어떻게 만들것인가
행을 누적하면서 막대기 그래프 최대 넓이 계산하듯 하면 된다.
백준 히스토그램과 굉장히 유사한데, 백준은 행 누적은 아니였던거 같음
누가 이것을 실버로 내었는가 나는 궁금하지 아니하지 않을 수가 없을 수가 없다.

## 정상까지 몇 번 갈아타나
단순 BFS 지만 각 정류장에서 정상까지 몇번 갈아타야 하는지 알아야 하므로
역방향 BFS 즉 정상에서 BFS를 한번 돌리면서 dist값 저장해주고 출력하면 된다.
역방향으로 진행하니 간선도 넣을때 반대로 넣어야한다.
여러번 BFS 안돌려도 됨
