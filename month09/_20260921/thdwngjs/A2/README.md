# 문제 요약
용량이 C로 같은 모두 같은 상자에 부품 N개를 모두 담을 때 필요한 최소 상자의 개수

# 아이디어
## 1. 무게 내림차순 정렬
큰 부품부터 넣어야 가지치기가 쉬워짐

## 2. 남은 무게 체크
(현재까지 사용 중인 상자의 남은 무게 + 남은 부품의 무게 합 / C) 개가 최소한으로 필요한 남은 가방
-> 이게 지금 최솟값보다 크면 더 연산할 필요 X

## 3. 무거운 것부터 들어가는 곳에 넣는 것은 정답이 아님

# 풀이
### 1. 무게 내림차순 정렬 및 역방향(?) 누적합 연산
앞서 설명한 가지치기를 위해서 정렬과 누적합 연산을 진행한다.
누적합은 남은 무게 추적을 쉽게 하기 위함

### 2. solve 함수를 통한 dfs 및 가지치기
* 가지치기
  * cnt >= min이면 return
    이미 확인한 최소 개수보다 더 필요하면 확인할 필요가 없음
  * i == N이면 min = cnt
    최소값 갱신
  * 남은 무게 체크 및 가지치기
    아이디어 2 참고
* 열린 상자 체크
  1. 반복문을 통해 열린 상자에 현재 보고자 하는 부품의 무게 cur이 들어갈 수 있는 지 확인
  2. 이전 박스에서 확인한 남은 무게면 더 확인 할 필요가 없음
  3. 그 이후 재귀함수를 통한 다음 부품 확인
* 새 상자를 열어 해당 부품 담기
  * min보다 더 작게 새 상자가 열리는 경우만 해당 로직 실행
