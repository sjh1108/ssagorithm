## 목표

주어진 숫자에서 `k`개의 숫자를 제거해 만들 수 있는 가장 큰 수를 구한다.

## 상태

- `k`: 앞으로 제거할 수 있는 남은 숫자의 개수
- `string_index`: 현재 확인할 `number`의 인덱스
- `deque`: 지금까지 확인한 숫자 중 결과로 선택한 숫자를 순서대로 저장

## 전이

현재 숫자가 deque의 마지막 숫자보다 크고 `k`가 남아 있다면 deque의 마지막 숫자를 제거한다.
숫자를 하나 제거할 때마다 `k`를 1 감소시키며, 조건을 만족하는 동안 반복한다.

더 이상 제거할 수 없으면 현재 숫자를 deque의 뒤에 추가하고 다음 인덱스로 이동한다.

```text
k > 0이고
deque가 비어 있지 않고
deque의 마지막 숫자 < 현재 숫자라면

deque의 마지막 숫자를 제거하고 k--
```

## 종료 조건

`number`의 모든 숫자를 확인하면 기본 반복을 종료한다.

모든 숫자를 확인한 뒤에도 `k`가 남았다면 deque의 뒤에서 `k`개의 숫자를 제거한다.
deque에 남은 숫자를 앞에서부터 문자열로 연결해 반환한다.

## 초기화

```text
k = 입력으로 받은 제거 횟수
string_index = 0
deque = 빈 상태
```

## 탐색 공간 및 복잡도

각 숫자는 deque에 최대 한 번 들어가고 deque에서 최대 한 번 제거된다.
내부에 `while`문이 있지만 이미 제거한 숫자를 다시 확인하지 않는다.

```text
시간 복잡도: O(n)
공간 복잡도: O(n)
```

## 손으로 실행해보기

```text
number = "1924", k = 2

1을 넣는다.
9가 1보다 크므로 1을 제거하고 k를 1 감소시킨 뒤 9를 넣는다.
2는 9보다 작으므로 그대로 넣는다.
4가 2보다 크므로 2를 제거하고 k를 0으로 만든 뒤 4를 넣는다.

deque = [9, 4]
반환값 = "94"
```

남은 제거 횟수가 있는 경우:

```text
number = "4321", k = 2

더 큰 숫자가 뒤에서 나오지 않아 기본 반복에서는 제거되지 않는다.
deque = [4, 3, 2, 1]

뒤에서 2개를 제거한다.
반환값 = "43"
```

## 풀이 후 배운 점

처음에는 남은 제거 횟수만큼의 범위에서 최댓값을 반복해서 찾으려고 했다.
이 방법은 같은 숫자를 여러 번 확인해 최악의 경우 `O(n²)`이 된다.

숫자를 왼쪽부터 한 번씩 확인하면서 이전에 선택한 작은 숫자를 deque에서 제거하면, 각 숫자를 최대 한 번 추가하고 한 번 제거하므로 `O(n)`으로 처리할 수 있다.

`String`에 `+=`로 결과를 연결하면 문자열을 반복해서 복사하므로 `StringBuilder`를 사용한다.
