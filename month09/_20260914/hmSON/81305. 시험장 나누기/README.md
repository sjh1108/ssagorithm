# PG_81305. 시험장 나누기


## 문제 분석
이진 트리 형태로 연결된 시험장에서 간선 `k-1`개를 끊어 `k`개의 그룹으로 나눌 때, **가장 인원이 많은 그룹의 인원을 최소화**해야 합니다.

간선 자체의 조합을 모두 시도하는 방식의 경우 시험장이 최대 `10,000`개인 상황에서 불가능할 것으로 보입니다. 따라서 어떤 간선을 끊어야 최대 그룹이 작아지는 지 보이는 그대로 판단하고 그 기준을 세우는 것은 비효율적일 것으로 판단하였습니다.


### 1. 이진 탐색을 위한 요구사항 재구성
따라서 이 문제의 요구사항을 재구성해 보기로 했습니다. 구하려는 값이 **최대 그룹 인원의 최소값**이므로 그 값을 **미리 정해 놓고 검증**하는 형태로 바꿔볼 수 있습니다.
<br>
그에 따라 재구성되는 새로운 요구사항은 다음과 같습니다.

> **각 그룹의 인원수를 제한한다고 할 때, 만들어지는 그룹의 수가 `k` 이하가 되게 하는 임의의 제한 인원 수 `x`를 구하여라**

각 원소의 최대값은 `10,000`이므로, 총 인원수는 최대 `100,000,000`입니다. 이를 이분 탐색을 수행하여 임의의 그룹 인원 제한수를 구하려 한다면 **27회 검증**으로 원하는 값을 구할 수 있을 것입니다.


### 2. 그룹 수 검증 과정
각 검증은 DFS 스택을 이용한 트리 후위 순회로 진행합니다.
1. 리프 노드부터 시작하여 자신과 하위 트리의 인원 수 합을 상위 노드로 반환
2. 각 상위 노드는 자신과 하위 트리의 인원 수 합이 제한 인원 수 `x`를 초과하는 지 확인
3. 초과하는 경우, 인원 수가 더 많은 하위 트리 하나를 별도 그룹으로 분리, 그래도 초과하면 나머지 하위 트리도 별도 그룹으로 분리
4. 남은 인원 수를 상위 노드로 반환하는 작업을 루트 노드까지 반복
5. 위의 DFS 과정을 거친 후의 그룹 수 반환
