# 적록색약

같은 색의 칸이 상하좌우로 이어진 구역을 센다. 적록색약인 경우에는 빨강(`R`)과 초록(`G`)을 같은 색으로 본다. [백준 10026번](https://www.acmicpc.net/problem/10026)

## 1. 접근 방법

처음에는 일반 탐색과 적록색약 탐색에 쓸 `visited` 배열을 각각 두고, BFS에서 색 비교 조건을 바꾸려고 했다. 두 번의 탐색을 순서대로 실행하므로 `countRegions()`를 호출할 때마다 그 안에서 새 `visited`를 만들면 방문 기록을 관리하기 편하다.

일반 구역 수를 먼저 구한 뒤 격자의 `R`을 모두 `G`로 바꿨다. 이렇게 하면 두 경우 모두 시작 칸과 같은 색의 이웃을 찾는 BFS를 그대로 사용할 수 있다.

## 2. 구현 방법

1. `countRegions()`에서 격자 전체를 순회한다. 아직 방문하지 않은 칸을 만나면 BFS를 시작하고 구역 수를 1 늘린다.
2. `bfs()`는 시작 좌표와 `visited`를 받는다. 시작 좌표에서 `targetColor`를 읽고, 상하좌우에서 범위 안에 있는 같은 색의 미방문 칸을 찾는다.
3. 칸을 큐에 넣을 때 방문 표시를 한다. 여러 이웃에서 같은 칸에 도달해도 큐에 한 번만 들어간다.
4. 일반 구역 수를 저장하고 `R`을 `G`로 바꾼 뒤 `countRegions()`를 다시 호출한다.

`bfs()`에 넘긴 `visited`는 `countRegions()`에서 만든 배열과 같은 객체다. 한 번의 `countRegions()` 안에서 시작한 모든 BFS는 방문 기록을 공유한다. [Java 풀이](./Main_100026_적록색약.java)

## 3. 시간 및 공간 복잡도

- **시간 `O(N²)`**. 각 탐색에서 모든 칸을 훑고, 각 칸을 큐에 최대 한 번 넣는다. 색을 바꾸는 데도 `O(N²)`이 걸린다.
- **공간 `O(N²)`**. 격자, 방문 배열, BFS 큐를 사용한다.
