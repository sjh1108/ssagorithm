# 문제 해석 및 풀이
A2와 마찬가지로 완전 탐색으로는 불가능해 보인다.
그렇다면 문제를 다시 읽어보자

$i$ < $j$ < $k$일때
a<sub>i</sub> > a<sub>j</sub> > a<sub>k</sub>
인 경우를 찾는 것이다.

그렇다면 이걸 분해해보면
$j$ < $i$ 에서
a<sub>i</sub> > a<sub>j</sub> 인 경우를 $l$

$j$ > $k$ 에서
a<sub>j</sub> > a<sub>k</sub> 인 경우를 $r$이라 명칭하면

$j$에서 $l$ * $r$이 각 $j$에서의 경우의 수이다.
그렇다면 전체 $l$과 $r$을 연산한 $L$ 배열과 $R$배열에서
$`L[i] * R[i]`$, $(0 <= i < N)$을 연산하면 되는 것이다.

# 구현
기본적인 골조는 A2의 코드와 유사하다.
하지만 세는 대상이 2가지로 늘어난다.

늘어나는 것을 연산하는 과정은 아래와 같다.

## 이전 값 가져오기
오른쪽 부분 집합에서 삽입을 할 때 `L[jj] += mid-1`과 `tmp++`을 하여 저장하는 과정을 추가한다.

이는 왼쪽 부분 집합에서 삽입하는 과정에 `R[ii] += tmp`를 통해 사용되며, 정렬되어 있던 값인 r인 값을 연산하는 것이다.

이 과정을 위해 각 인덱스를 저장할 필요가 있어 `idx`배열을 사용했다.

그 외에는  A2 풀이와 유사하다.
