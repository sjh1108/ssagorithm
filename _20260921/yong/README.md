## 관측소 통신망 개통
1 ~ N 번 관측소 존재, 케이블 M개(1 2 -> 1번과 2번 관측소를 연결), 처음으로 다 연결 되는 순간의 케이블 번호 구하기
노드간 연결 확인이 필요함 유니온 파인드로 풀수 있을것 같음
1. 케이블 주어지면 유니온파인드 
2. 한번 연결 할때마다 전체가 연결 되었는지 확인

**루트 찾기(find) 경로 압축**
경로 압축 x, return find(parent[v]) 
4 -> 3 -> 2 -> 1
다음에 find(4) 하면 또다서 4 -> 3 -> 2 -> 1

경로 압축 o, return parent[v] = find(parent[v])
루트 찾고 재귀 돌아오면서 4 -> 1, 3 -> 1, 2 -> 1 세팅
다음에 find(4) 했을떄 바로 4 -> 1

잔실수
전체가 연결됨을 확인할때 각각의 루트를 확인해야함
각 부모 parent[i]가 아닌 find(i) 가 논리적으로 적절함

## 컨베이어 벨트의 다음 높은 부품
부품 N개가 있음. 각 부품 하나하나 마다 자신의 오른쪽에 있으면서 높이가 자기보다 큰 처음 부품의 위치를 기록
막대기 그래프로 생각해서 풂(가장 오른쪽 막대부터 오른쪽으로 선을 긋는방식)

가장 오른쪽부터 스택에 넣어두고 시작(오른쪽에 아무것도 없으므로 -1)

오른쪽부터 보면서, 현재 부품보다 낮거나 같은 부품은 앞으로도 답이 될 수 없으므로 스택에서 제거
현재 높이보다 스택에 들어있는 높이가 작으면 pop -> 현재 부품 높이가 더 왼쪽에 있으면서 더 높으므로
스택에 들어있는 높이가 더 높으면 기록하면 됨

현재 높이보다 크면 기록

## 전화번호 목록
전화번호에 적힌 번호 중 한 번호가 다른 번호의 접두어인 경우가 있는지 체크
-> 해시로 전화번호 등록해두고 검색 하는 방식으로 풀이
내 방식: 각 번호의 접두어들을 모두 등록하고(자신 제외) 검색 하는 방식
다른 방식: 각 번호(자신의 번호)만 등록해 두고 검색할 번호의 접두어들을 검색하는 방식
