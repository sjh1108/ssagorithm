## 배달
1번 마을에서 각 마을로 배달, K시간 이하로 배달 가능한 마을만 출력
[다익스트라]
1번마을에서 각 마을까지 최단 거리 구하기
K이하인 마을만 출력

## 상위 기지 판정
본부까지 가는 경로는 하나뿐, u가 v의 상위기지 인지 대답해야함
v -> 1 dfs는 대답 할때마다 dfs 돌려야 함. O(N * Q)
1에서 dfs 돌리면서 in시간 out시간 기록 후 Q 판단(N + Q)


## 필사본의 길이
소문자 알파벳 하나는 글자 하나를 뜻함, k[x]는 x글자열을 k번 붙인것을 뜻함 , 표기를 이어쓰면 글자열도 그 순서대로 이어 붙임
문제를 보면서 뭔가 후위 표기법, 전위 표기법 처럼 스택을 활용하면 될거 같았음
가장 안쪽 글자열 부터 풀어가면서 연산하면 될거 같음 -> 스택에 push 하다가 ] 만나면 pop 하면서 연산
이러면 [[]] 같은경우는 괜찮지만 [] [] 이렇게 따로 있어도 중첩 계산 해버림
괄호마다 독립적으로 계산해야함
[ 만나면 이전길이 저장, ]만나면 압축길이 계산 후 이전 길이 합산
