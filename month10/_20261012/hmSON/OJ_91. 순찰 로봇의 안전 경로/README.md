# OJ_91. 순찰 로봇의 안전 경로

요구사항은 크게 2가지로, 로봇의 이동 경로 내 각 칸의 안전도 중 최소값을 의미하는 "안전 등급"과 로봇이 `S`에서 `E`까지 도달하는 "최단 경로"

각 칸의 안전도(가장 가까운 분출구까지의 거리)를 구한 뒤, **`S -> E` 경로의 안전 등급을 최대화하고 동시에 그 안전 등급을 준수하는 최단 경로를 구해야 함**


## 1. 격자 전체의 안전도 -> 멀티 소스 BFS

각 가스 분출구를 시작 지점으로 두는 멀티 소스 BFS 한 번으로 각 칸의 안전도를 구할 수 있음(가스 분출구 자신의 위치는 안전도 0)
<br>
격자 전체를 한 번만 훑으므로 $O(HW)$


## 2. 안전 등급 확정을 위한 요구사항 재구성 -> 매개변수 탐색

요구사항의 우선순위를 따졌을 때 "최단 경로"보다 "최대 안전 등급"이 먼저이므로, 안전 등급의 확정을 위해 문제에서 묻는 질문을 재구성

> **안전 등급을 임의의 값 `X`로 제한했을 때 로봇이 `S -> E`로 이동할 수 있는가?**
><br>
> **위 조건을 충족하는 안전 등급 `X`의 최대값은?**

판정이 단조적(`X`가 가능하면 그 이하도 가능, 불가능하면 그 이상도 불가능)이므로 매개변수 탐색이 성립됨

- 하한 `0`: 가스 분출구 통과까지 허용하는 최소 기준. 이조차도 이동이 불가능하면 벽에 의해 이동 불가능한 것으로 간주
- 상한 `min(dist[sy, sx], dist[ey, ex])`: 출발점과 도착점 두 칸은 반드시 밟아야 하므로 그 안전도를 초과할 수 없음


## 3. 안전 등급 검증과 최단 경로 측정을 동시에 수행 -> BFS

임의의 안전 등급 `X` 미만인 칸을 벽으로 취급하고 `S`를 시작점으로 두는 BFS 수행. `E`에 도달하면 통과

**해당 BFS에서 `E`에 처음 도달했을 때의 이동 횟수가 곧 해당 안전 등급 `X`를 준수했을 때의 최단 경로**


## 4. 도달 불가 판정 -> 안전 등급 -1

모든 열린 칸의 안전도가 유한함이 보장된 상태에서 가스 분출구 통과를 허용하는 조건(안전 등급 `X = 0`인 경우)에서도 `S -> E` 도달에 실패할 경우 `S`와 `E`는 벽에 의해 완전히 분리되었다고 판단


## 5. 복잡도
- 멀티 소스 BFS : $O(HW)$, 최초 1회
- 판정 BFS : 호출당 $O(HW)$
- 이분 탐색 : 약 $\log(HW)$회, 18회 내외

전체 $O(HW \log(HW))$. `500 × 500` 기준 약 $4.5 \times 10^6$ 연산. 공간은 $O(HW)$.
