# OJ 116 ~ 118

마을 `N` 개가 트리를 이룰 때, 마을 사이의 **거리**를 다루는 세 문제<br>
BFS라는 도구를 유지한 채 **거리를 구하는 문제에서 배치를 결정하는 문제**로 성격이 바뀜


## 116. 산골 마을의 소문

**요구사항** : 한 마을에서 소문이 퍼질 때 모든 마을이 듣는 시각 `T`와, 시각별로 소문을 처음 듣는 마을의 수

소문이 한 턴에 인접 마을로 한 칸씩 퍼지므로, 각 마을이 듣는 시각은 **시작 마을로부터의 최단 거리**와 같음

> **핵심** : 모든 이동 비용이 1이므로 BFS 한 번으로 전부 해결

마을을 방문하는 순간이 곧 그 마을이 처음 듣는 시점이므로, 큐에 넣을 때 해당 시각의 카운트를 올리면 분포가 자연히 집계됨


## 117. 중계탑 사각지대

**요구사항** : 중계탑이 `M` 개 있을 때, 출력 후보 `K` 마다 전파가 닿지 않는 마을의 수

### 출발점이 여럿
116은 시작 마을이 하나였지만, 여기서는 중계탑이 `M` 개<br>

> **모든 중계탑을 한꺼번에 큐에 넣고 BFS를 시작하면, 각 마을에 처음 도달하는 시점이 곧 가장 가까운 탑까지의 거리**

이것이 다중 소스 BFS이며, 한 번의 순회로 전부 해결됨

### 질의 처리
116은 결과를 한 번만 출력했지만, 여기서는 출력 후보가 `Q` 개<br>
후보마다 다시 순회하면 역시 복잡도가 폭발

116에서 이미 "거리별 마을 수"를 집계하고 있었다는 점에 주목하면 해결됨

> **거리별 개수에 누적합을 적용해 두면, 각 질의는 `n - cntByDist[K]` 한 번의 참조로 끝남**

전처리 `O(N)` + 질의당 `O(1)` 구조로, 116의 집계 결과를 질의에 재활용하는 형태


## 118. 중계탑 최소 설치

**요구사항** : 출력이 `K` 로 고정일 때, 모든 마을을 덮기 위해 필요한 중계탑 수의 최솟값

### 직전 문제와의 차이 : 탐색에서 최적화로
117은 **탑의 위치가 주어진 상태에서 거리를 구하는** 문제였음<br>
118은 **탑을 어디에 세울지 결정하는** 문제이므로 성격이 근본적으로 다름

단순 BFS로는 해결되지 않고 그리디 판단이 필요

### 그리디의 근거
아직 덮이지 않은 마을 중 **가장 깊은 곳**을 보면 선택지가 하나로 좁혀짐

> **그 마을에서 루트 방향으로 정확히 `K` 칸 올라간 지점이 최선**

더 가까이 세우면 위쪽을 덜 덮어 손해이고, 더 멀리 세우면 그 마을 자체가 덮이지 않음<br>
자기보다 깊은 마을은 이미 처리되었으므로 아래쪽은 고려할 필요가 없음

따라서 **깊이 내림차순 정렬 → 미덮인 마을 발견 시 K칸 위에 설치 → 거리 K까지 전파** 를 반복

### 구현상의 전환
117의 다중 소스 BFS와 달리, 여기서는 **탑마다 BFS가 반복**됨<br>
매번 방문 배열을 초기화하면 `O(N²)`이 되므로, 탑 번호를 기록하는 방식으로 초기화 자체를 제거

> `spread[v]` 의 세 가지 상태<br>
> `0` : 미전파 / `towerIdx` 와 일치 : 이번 BFS에서 방문 / 그 외 : 이전 탑이 전파


## 시리즈 정리

| | 116 | 117 | 118 |
|---|---|---|---|
| 문제 성격 | 거리 구하기 | 거리 + 질의 | 배치 최적화 |
| 출발점 | 1개 | M개 (다중 소스) | 매 반복마다 결정 |
| 핵심 도구 | BFS | 다중 소스 BFS + 누적합 | 그리디 + 반복 BFS |
| 마을 수 | 5,000 | 200,000 | 200,000 |

**단일 소스 → 다중 소스와 질의 → 배치 최적화**로 요구사항의 성격이 바뀌는 흐름<br>
116에서 만든 "거리별 집계"가 117의 누적합으로 이어지고, 117의 전파 개념이 118의 그리디 판단 근거가 됨
