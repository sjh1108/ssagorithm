## 내가 이해한 문제

입력으로는

begin 시작 단어
targe 목표 단어
words 단어 풀

시작 단어에서 목표 단어가 되어야 한다
그러기 위해서는 규칙 두가지

한번에 하나의 알파벳을 바꿀 수 있다
words에 있는 알파벳으로만 바꿀 수 있다

두개를 이용해서 단어를 바꿔서

target 단어를 만든뒤

target 단어가 되기 위해서 몇번의 변환?을 했는지를 return 하는것이 문제의 최종 목표이다.

## 상태

cur string 현재 알파벳
count 현재 바뀐 상태의 개수
visit[] 방문 처리

## 전이

변환 가능 한 nextword가 선택 된다면
curStirng, count -> nextword,count+1로 바뀐다.

## 제약

아직 방문 하지 않았으며
하나의 알파벳만 다른 단어인 경우 이동 가능하다

## 후보별 초기화

새로운 후보는 없으나
시작 할때
visit
count
cur string은 start 알파벳으로 초기화 시켜줘야함

## 목표

begin에서 target 까지 이동 했을때 
몇번 변환 시켜서 이동을 하는가?


## 탐색 공간

- 선택 대상: curstring
- 후보 하나의 형태: ??
- 전체 후보 수: wordslength
- 후보 하나의 검사 비용: o(n)? n = words.length
- 전체 예상 비용: 단어길이 * 단어 개수 ^2
