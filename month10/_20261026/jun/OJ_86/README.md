# 86 천문 시계의 톱니

---

실버 / 분할 정복, 수학

---

$b$ 가 $10^{18}$ 까지 커질 수 있으므로 $a$ 를 $b$ 번 곱하는 방법으로는 시간 안에 끝낼 수 없다.
=> 분할 정복
``` text
2² = 2  × 2  = 4
2⁴ = 2² × 2² = 4 × 4   = 16
2⁸ = 2⁴ × 2⁴ = 16 × 16 = 256
```

---

$a^{b}$ $mod$ $m$

```text
2¹⁰ = 1024 = 1000 + 24

1024 × 1024
= (1000 + 24) × (1000 + 24)
= 1000 × 1000
  + 1000 × 24
  + 24 × 1000
  + 24 × 24
```
```text
2¹⁰ % 1000 = 24

2²⁰ % 1000
= (2¹⁰ × 2¹⁰) % 1000
= (24 × 24) % 1000
= 576
```
```text
짝수: a²ᵏ   = aᵏ × aᵏ
홀수: a²ᵏ⁺¹ = aᵏ × aᵏ × a
```
```text
(A × A) % M
= ((A % M) × (A % M)) % M

(A × A × a) % M
= (((A % M) × (A % M)) % M × (a % M)) % M
```
