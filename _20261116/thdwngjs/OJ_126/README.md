# 고민
1. 결국 ^ 연산자를 한다면 최상위 비트부터 계속해서 연산하면 되지 않을까? 
2. 그럼 가능한 상위 비트부터 1로 채우다 보면 답을 연산할 수 있을 것이다.

# 해결
1. 우선 높은 비트부터 후보를 확정 짓는다.
  ans는 현재까지 확정지은 후보 비트들이고, cand를 통해 현재 반복문에서 확인할 비트를 작성해둔다.
  예를 들어 ans = 1000(2)이고, 확인할 비트 b가 2이면 cand는 1100(2)이 되는것
  만약 cand가 가능하면 ans = cand로 확정짓고 다음 비트 연산
2. 그럼 후보 배열에서 현재 확인중인 비트까지만 남겨두고 HashSet에 저장해둔다.
3. XOR 후보가 가능한지 확인
  A^B = C일때, B = A^C가 성립하기 때문에
  XOR 결과가 C가 되도록 하는 두 숫자 x, y가 존재하는지 확인하려면
  y = x^c를 만족하는 y가 집합에 존재하는지 확인하면 된다.

# 풀이
## 1. 높은 비트부터 확인
```java
int ans = 0;

for(int b = 29; b >= 0; b--){
  int cand = ans | (1 << b);
}
```
현재 확인할 비트를 OR 연산을 통해 ans와 연결한다

## 2. HashSet에 접두 비트 저장
```java
Set<Integer> pre = HashSet<>();

for(int x: arr){
  set.add(x >> b);
}
```
현재 확인할 비트보다 낮은 비트는 버리고 현재 확인할 비트까지만 남겨두는 것

## 3. XOR 후보가 가능한지 확인
```java
int c = cand >> b;

for(int x: set){
  if(set.contains(x ^ c)){
    ans = cand;
    break;
  }
}
```
앞서 설명한 X^Y = C -> Y = X ^ C이기 때문에
X^C인 값이 존재하는지 확인하면 된다.
