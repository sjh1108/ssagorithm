# 네트워크

- 문제 링크: https://school.programmers.co.kr/learn/courses/30/lessons/43162
- 유형: DFS/BFS, 그래프 탐색, 연결 요소
- 작성 시기: 2026년 7월 4주차

## 내가 이해한 문제

- DFS 또는 BFS를 사용한다.
- 아직 방문하지 않은 컴퓨터를 발견하면 그 컴퓨터에서 탐색을 시작한다.
- 시작한 컴퓨터와 연결된 모든 컴퓨터를 방문 처리한다.
- 한 번의 탐색으로 하나의 네트워크 전체가 방문 처리된다.
- 다시 전체 컴퓨터를 확인하면서 아직 방문하지 않은 컴퓨터를 만나면 새로운 네트워크이므로 네트워크 수를 1 증가시킨다.
- 최종적으로 서로 연결된 컴퓨터 덩어리의 개수를 구한다.

## 처음 작성한 모델링

### 상태

- `visit`: 네트워크 방문 배열
- `ncount`: 네트워크 개수

### 전이

- 아직 방문하지 않은 컴퓨터를 방문 처리한다.
- 아직 방문하지 않은 컴퓨터라면 네트워크 수를 1 증가시키고 DFS를 실행한다.
- 한 컴퓨터에서 방문 가능한 모든 컴퓨터를 방문 처리한다.

### 제약

- 배열 범위 밖의 컴퓨터를 확인하면 안 된다.
- 이미 방문한 컴퓨터는 다시 탐색하지 않는다.

### 목표

- 서로 연결된 컴퓨터 덩어리인 네트워크의 개수를 구한다.

### 풀이 방향

1. `0`번부터 `n - 1`번 컴퓨터까지 확인한다.
2. 아직 방문하지 않은 컴퓨터라면 방문 처리한다.
3. 새로운 네트워크를 발견했으므로 네트워크 수를 1 증가시킨다.
4. DFS를 시작해 연결된 모든 컴퓨터를 방문 처리한다.
5. DFS가 끝나면 전체 컴퓨터를 확인하는 반복문을 계속 진행한다.

## 피드백

전체 풀이 방향과 코드는 맞다. 바깥 반복문은 새로운 네트워크의 시작점을 찾고, DFS는 그 시작점과 같은 네트워크에 속한 모든 컴퓨터를 방문 처리한다.

모델링에서 빠진 핵심 상태는 DFS가 현재 확인하고 있는 컴퓨터 `num`이다. `visit`만으로는 어느 컴퓨터의 연결 정보를 검사하는지 표현할 수 없으므로 현재 컴퓨터도 상태에 포함해야 한다.

`ncount`는 DFS가 들고 이동하는 상태라기보다, 지금까지 발견한 연결 요소의 개수를 저장하는 정답 누적 변수다.

## 피드백 반영 모델링

### 상태

- `num`: DFS가 현재 확인하고 있는 컴퓨터
- `visit[i]`: `i`번 컴퓨터가 이미 어떤 네트워크에 포함된 것으로 확인됐는지
- `ncount`: 지금까지 발견한 네트워크 수를 저장하는 정답 누적값

### 전이

현재 컴퓨터 `num`과 직접 연결된 컴퓨터 `i`를 찾는다.

```text
num → i
```

`i`가 아직 방문되지 않았다면 다음 순서로 탐색한다.

1. `visit[i] = true`로 변경한다.
2. `dfs(i)`를 호출한다.
3. `i`와 연결된 컴퓨터를 계속 탐색한다.

### 제약

- `computers[num][i] == 1`인 컴퓨터로만 이동할 수 있다.
- 이미 방문한 컴퓨터는 다시 탐색하지 않는다.
- 컴퓨터 인덱스는 `0` 이상 `n - 1` 이하여야 한다.

현재 코드의 `if (i == num) continue;`는 사용해도 되지만 필수는 아니다. 현재 컴퓨터는 DFS에 들어오기 전에 이미 방문 처리되므로 `if (visit[i]) continue;`에서 걸러진다.

### 목표

- 바깥 반복문에서 아직 방문하지 않은 컴퓨터를 발견할 때마다 새로운 네트워크 수를 1 증가시킨다.
- DFS 한 번으로 해당 컴퓨터와 같은 네트워크에 속한 모든 컴퓨터를 방문 처리한다.
- 모든 컴퓨터를 확인한 뒤 네트워크 수를 반환한다.

## 막힌 부분

- DFS 내부에서 어떤 조건을 검사해야 하는지 모델링에 충분히 적지 않아 구현할 때 조금 지체됐다.
- 현재 컴퓨터 `num`과 연결 여부 `computers[num][i] == 1`을 상태와 제약에 명시하지 않았다.

## 이번 문제에서 배운 점

### 바깥 반복문과 DFS의 역할

```text
바깥 반복문
→ 새로운 네트워크의 시작점을 찾는다.

DFS
→ 시작점과 같은 네트워크에 속한 컴퓨터를 모두 방문한다.
```

네트워크 수는 컴퓨터를 하나 방문할 때마다 증가하는 것이 아니라, 바깥 반복문에서 아직 방문하지 않은 새로운 시작점을 발견했을 때만 증가한다.

### 피로도 문제와 방문 배열의 차이

```text
피로도
→ 현재 탐색 순서에서 선택한 던전을 표시한다.
→ 다른 순서를 탐색해야 하므로 재귀 호출 후 방문을 복구한다.

네트워크
→ 이미 어느 네트워크에 포함된 것으로 확인한 컴퓨터를 표시한다.
→ 다시 다른 네트워크로 세면 안 되므로 방문을 복구하지 않는다.
```

같은 DFS와 `visited` 배열을 사용하더라도 문제에서 방문이 의미하는 것이 다르면 복구 여부도 달라진다.

### 복잡도

- 인접 행렬의 각 행을 DFS에서 확인하므로 시간 복잡도는 `O(n²)`이다.
- 방문 배열과 재귀 호출에 필요한 공간은 `O(n)`이다.
